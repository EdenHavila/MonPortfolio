# Dossier CV

Dépose ton fichier PDF ici, par exemple :

    CV-Eden-Havila-Kouame.pdf

Puis mets à jour le lien dans `index.html` (bouton "Télécharger mon CV"
dans la navbar) pour qu'il pointe vers ce nom de fichier exact :

    <a href="assets/cv/CV-Eden-Havila-Kouame.pdf" download class="btn btn-ghost btn-small">
      Télécharger mon CV
    </a>

L'attribut `download` force le téléchargement plutôt que l'ouverture
dans un nouvel onglet.
