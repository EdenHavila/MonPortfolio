# Dossier logos de certifications

Dépose ici les logos des organismes certificateurs, au format PNG/SVG,
fond transparent de préférence. Exemple de nommage :

    ceh-logo.png
    comptia-security-plus-logo.png
    iso27001-lead-auditor-logo.png

Chaque logo est ensuite référencé dans la carte de certification
correspondante dans `index.html` (voir section Certifications).
Dimensions recommandées : 64x64px minimum, format carré ou proche.
